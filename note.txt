ReactJS Project 
-------------------
    - "react" library 
        - helps to create / compose components 

    - "react-dom" library 
        - responsible to render the components 

1. Components 
    - represents a piece / section / part etc. on a webpage 
    - a component is javascript function, returns the markup (UI description) 


        function Header() {
            return (
                //jsx/tsx code 
                <div>
                    <h1>This is heading</h1>
                </div>
            )
        }

        const root = createRoot(document.getElementById('root))
        root.render(<Header />)
        

2. JSX / TSX 
    - JSX   : javascript + html like syntax
    - TSX   : typescript + jsx
    - javascript extension used to describe UI in reactjs 
    - both jsx/tsx let you write React Component and describe the UI using jsx syntax 
        - jsx syntax looks much similar to html 
    - jsx code is converted to its equivalant js code 
    - Babel does that conversion
